# Launch roadmap

**The initial release is agent-first and headless.** A graphical application is deferred. The existing website remains the information and download surface.

These are launch outcomes, not promised dates or claims that all capabilities are already available.

| Milestone | Customer outcome |
|---|---|
| Connect | A supported local AI client connects to an unrelated addon and returns a useful read-only result. |
| Validate | The qualified distribution performs a supported native Workbench check and explains missing prerequisites or a failed check accurately. |
| Resume | An interrupted client reconnects and recovers the existing operation and result without repeating completed work. |
| Remember | The agent retrieves relevant project knowledge with clear evidence scope and project isolation. |
| Install and support | The exact artifact has clear installation, compatibility, permissions, upgrade, removal, and troubleshooting instructions. |
| Release | External users complete the advertised agent workflow using the qualified artifact and published contract. |

The current read-only companion provides a starting point for the connection milestone. Full native execution and Brain integration remain planned. See [capabilities](CAPABILITIES.md).

## Launch scope

Use the existing local companion and framework. Keep setup lightweight and support terminal-based diagnostics. No graphical product workflow, mandatory hosted account, paid service, or language rewrite is a prerequisite for the initial launch.

Optional hosted work is a separate future track. A later graphical interface can be considered when real usage establishes a need. Details of the private implementation plan are maintained outside this repository.
